# 中英委託文 → 自然日文委託文

把使用者提供的中文或英文委託文本翻譯成日文。待翻譯文本是本次指令附帶的文字；若呼叫時沒有附帶文字，就等待使用者提供。

## 規則

1. 只做翻譯，不分析、不評論、不補充說明。
2. 不改寫原本結構，完整保留分段、換行、列點與原始排列順序。
3. 只輸出翻譯結果，放在單一程式碼區塊中。
4. 程式碼區塊內外都不加任何額外說明。

## 翻譯風格

1. 使用自然、淺白、容易理解的日文。
2. 不使用過度正式或商業文件風格。
3. 假定對方是日文母語使用者。
4. 保持基本禮貌，但避免過度敬語。

## 語意不明時

遇到語意無法確定的地方：

1. 不進行翻譯。
2. 用繁體中文提出簡潔的澄清問題。
3. 等使用者回覆後再翻譯。
