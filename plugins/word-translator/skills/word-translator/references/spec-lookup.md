# 規格出處查證

使用者要求附出處（章節位置）時才讀這份。目的是讓使用者能回頭核對：這個術語在規格裡真的是這樣寫，位置在哪。

## 為什麼要實際讀規格

憑記憶給章節號很容易編錯，而且看起來很可信；錯的出處比沒有出處更糟。所以章節位置只能來自實際讀到的規格文字，不能來自記憶。

## 流程

1. 確定是哪一份規格與版本（使用者沒講版本就用現行版，並在出處標明版本）。
2. 用可用的網頁搜尋或讀取工具，找該規格的官方或公開全文來源，讀到定義或使用該術語的段落。
3. 以規格裡實際出現的詞為準，決定譯詞；若與先前憑記憶的結論不同，以規格為準。
4. 在該譯詞區塊的例句之後加一行出處，格式如下。

```
> 出處：<規格名稱與版本> §<章節編號> <章節標題>
```

- 一個譯詞只標最能代表其定義或用法的一處，不堆砌。
- 能附連結時附在同一行末。

## 讀不到規格全文時（付費、需登入、搜尋不到）

可以用二手來源（授權轉載、官方公開的摘錄、標準化組織或政府的說明、教材與稽核指引等），但章節位置要有交叉佐證：

- 至少要有 2 個彼此獨立的二手來源，且它們指出的章節位置一致，才能標章節。獨立的意思是不互相引用、不是同一份文件的轉載。
- 各來源章節位置不一致、只找到 1 個來源，或來源只佐證定義而沒有章節時，不標章節。
- 只能標二手來源時，一律寫明「未見原文，依二手來源」，並列出用到的來源，讓使用者能核對。

三種結果的格式：

```
> 出處：<規格名稱與版本> §<章節編號> <章節標題>（未見原文，依二手來源：<來源1>、<來源2>）
> 出處：<規格名稱與版本>（二手來源未能共同佐證章節位置，未標章節）
> 出處：未查證（找不到可用來源）
```

不要給「大概在某章」這類說法。
